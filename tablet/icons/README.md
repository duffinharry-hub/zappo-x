# Console pictures

The console list's pictures on the tablet: the **Systematic** icons from
RetroArch's assets ([libretro/retroarch-assets](https://github.com/libretro/retroarch-assets),
`xmb/systematic/png`), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) by the libretro
team. Made smaller for Zappo X by `tools/console_icons.py`; otherwise as they
are. `tablet/setup-card.py` copies them to the card's `CFW/clove/icons`
(a picture you put there yourself is kept).
