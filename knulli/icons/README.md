# Console pictures (Zappo X on Knulli)

The console list's pictures: the **Systematic** icons from RetroArch's assets
([libretro/retroarch-assets](https://github.com/libretro/retroarch-assets),
`xmb/systematic/png`), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) by the libretro team.
Cropped and made smaller by `tools/knulli_icons.py` (one per console Knulli
knows, named by Zappo's console code); otherwise as they are. The package puts
them in `/userdata/system/zappo-x/icons`.
